GIGGO REFERENCE-GAP BACKLOG
===========================

Purpose
-------
This file lists functionality found in the TalentHive codebase but missing or
incomplete in Giggo. We will implement it one vertical slice at a time.

Audit baseline: 2026-09-20
- TalentHive baseline: main / origin/main
- Giggo baseline: main / origin/main in both frontend and backend repositories
- Important: Frontend PR #31 and backend PR #10 are merged, their remote
  feature branches are deleted, and both local main branches are synchronized.

Status markers
--------------
[ ] Not started in Giggo
[~] Partially present in Giggo or incomplete in the TalentHive reference
[!] TalentHive code exists but is broken, simulated, unmounted, or unsuitable
    for direct copying; redesign and verify it before implementation
[x] Completed in Giggo and not part of this missing-feature backlog

Definition of done for every item
---------------------------------
An item moves to complete only after its UI, API contract, server-side
validation, authorization, persistence, failure states, relevant indexes,
automated tests, production build, and authenticated browser journey pass.
Secrets must remain in ignored environment files. Each item should be delivered
through a focused branch and reviewed pull request.
